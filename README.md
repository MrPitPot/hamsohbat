# همصحبت (Hamsohbat)

یک برنامه‌ی گفتگوی متنی، صوتی و تصویری شبیه دیسکورد برای جمع‌های دوستانه؛ بدون فروشگاه، کوئست و نیترو.
کل برنامه روی Cloudflare Workers اجرا می‌شود و به هیچ سرور دیگری نیاز ندارد.

## امکانات

- **حساب کاربری:** ثبت‌نام و ورود با نام کاربری و رمز، پروفایل (آواتار، نام نمایشی، بیو، رنگ بنر)، وضعیت (آنلاین، بی‌کار، مزاحم نشوید، نامرئی) و وضعیت سفارشی
- **دوستان:** درخواست دوستی با نام کاربری، پذیرفتن/رد، حذف، بلاک
- **پیام مستقیم:** گفتگوی دونفره و گروهی (تا ۱۰ نفر)، تماس صوتی و تصویری با زنگ خوردن
- **سرور:** ساخت سرور، آیکون، لینک دعوت (با انقضا و سقف استفاده)، دسته‌بندی، کانال متنی و صوتی، جابه‌جایی کانال‌ها با کشیدن
- **نقش و دسترسی:** نقش‌های رنگی با ۱۵ دسترسی، سلسله‌مراتب نقش‌ها، نام مستعار، اخراج، مسدودسازی، واگذاری مالکیت
- **پیام:** ویرایش، حذف، پاسخ، واکنش ایموجی، منشن (`@نام` و `@everyone`)، سنجاق، جستجو، مارک‌داون (**پررنگ**، *کج*، ~~خط‌خورده~~، `کد`، بلوک کد، نقل‌قول، اسپویلر)، نشانگر «در حال نوشتن»، پیام‌های خوانده‌نشده و شمارنده‌ی منشن
- **فایل:** ارسال عکس، ویدیو، صدا و فایل تا ۲۵ مگابایت (کشیدن، چسباندن یا انتخاب)
- **صدا و تصویر:** کانال صوتی، بی‌صدا/بستن صدا، دوربین، اشتراک صفحه (همراه صدا)، نشانگر صحبت کردن، تنظیم بلندی هر نفر، انتخاب میکروفون و بلندگو، حذف نویز و اکو
- **رابط کاربری:** فارسی (راست‌چین) و انگلیسی، پوسته‌ی تیره و روشن، سازگار با موبایل و قابل نصب روی گوشی، اعلان دسکتاپ
- **افکت‌های صوتی:** ورود و خروج خودتان و دیگران، میوت، دیفن، اشتراک صفحه، پیام، منشن، زنگ تماس ورودی و خروجی (با تنظیم بلندی)
- **بیشتر:** پیام صوتی، پیش‌نمایش لینک و یوتیوب، Push-to-Talk و حساسیت میکروفون، بی‌صدا کردن سرور/کانال/گفتگو، خط «پیام‌های جدید»، تیتر و لیست در پیام، تصویر در تصویر، بیرون کردن از کانال صوتی، میانبرهای Ctrl+Shift+M و Ctrl+Shift+D
- **انواع کانال:** متنی، صوتی، انجمن (Forum)، اطلاع‌رسانی (فقط ناظران می‌نویسند)، صحنه (Stage: سخنران‌ها و شنونده‌ها، بالا بردن دست، دعوت به صحبت)، رشته (Thread) از روی پیام یا مستقیم، بایگانی رشته‌ها
- **دسترسی هر کانال:** کانال و دسته‌ی خصوصی، اجازه/رد/پیروی برای هر نقش یا عضو (مثل دیسکورد)، همگام‌سازی با دسته، حالت آهسته (Slowmode)، کانال دارای محدودیت سنی، سقف کاربر و بیت‌ریت کانال صوتی
- **بیان:** ایموجی اختصاصی سرور (در پیام و واکنش، با تکمیل خودکار `:نام:`)، استیکر، ساندبورد (صداهای سرور + ۱۰ صدای پیش‌فرض)، نظرسنجی (یک یا چند گزینه، مدت‌دار)
- **پیام:** هدایت (Forward)، علامت نخوانده، کپی لینک و شناسه‌ی پیام، خواندن پیام با صدا، منشن کانال (`#نام`) و نقش، زمان‌های `<t:…>`، لینک‌های `[متن](آدرس)`، پیوست اسپویلر، روشن/خاموش کردن منشن در پاسخ، صندوق منشن‌ها (Ctrl+I)
- **مدیریت سرور:** رویدادها (Events)، وب‌هوک‌های سازگار با دیسکورد (همراه Embed)، مدیر خودکار (واژه‌های ممنوع، لینک، دعوت، منشن انبوه)، گزارش فعالیت‌ها (Audit Log)، محرومیت موقت (Time Out)، بی‌صدا/ناشنوا کردن سروری، جابه‌جایی افراد بین کانال‌های صوتی، بنر و توضیحات سرور، تنظیم اعلان برای هر سرور (همه/فقط منشن/هیچ)
- **حساب:** تأیید دومرحله‌ای با برنامه‌ی Authenticator (کد QR)، تغییر نام کاربری، حذف حساب، ضمیرها، یادداشت خصوصی روی کاربران، وضعیت «بیکار» خودکار، نمایش بازی در حال اجرا (برنامه‌ی ویندوز)
- **ناوبری:** جابه‌جایی سریع (Ctrl+K)، پوشه‌ی سرورها و مرتب‌سازی با کشیدن (مثل دیسکورد: سرور را روی سرور دیگر بیندازید)، Alt+↑/↓ بین کانال‌ها، Ctrl+Alt+↑/↓ بین سرورها
- **ظاهر:** تم‌های روشن، خاکستری، تیره و تیره‌ی مطلق، ۲۱ تم رنگی گرادیانی و تم دلخواه، رنگ تأکیدی، حالت فشرده، اندازه‌ی قلم، فاصله‌ی پیام‌ها، بزرگ‌نمایی، کاهش حرکت و انیمیشن برای همه‌چیز
- **وارد کردن از دیسکورد:** با لینک قالب سرور (کانال‌ها و نقش‌ها) یا با یک ربات (کانال‌ها، نقش‌ها، دسترسی‌ها، ایموجی‌ها و پیام‌های اخیر)
- **تیم‌اسپیک:** اتصال به سرور TeamSpeak 3 از داخل برنامه‌ی ویندوز (کانال‌ها، صحبت، چت، تلنگر)

## برنامه‌ی ویندوز

نصب‌کننده‌ی استاندارد ویندوز (`Hamsohbat-Setup.msi`، حدود ۲٫۴ مگابایت). بدون نیاز به دسترسی ادمین برای همان کاربر نصب می‌شود، در منوی Start و دسکتاپ میانبر می‌سازد و از «Apps & features» ویندوز قابل حذف است.
رابط کاربری داخل خود فایل برنامه قرار دارد (وب‌سایت باز نمی‌کند)؛ فقط پیام‌ها و صدا از سرور می‌آیند. موتور نمایش، WebView2 خود ویندوز است، برای همین حجمش کم است.

- آیکون کنار ساعت، باز ماندن در پس‌زمینه، اجرا با ویندوز
- مثل دیسکورد، وقتی در ویس هستید آیکون کنار ساعت به یک دایره تبدیل می‌شود که با صحبت کردن پر و خالی می‌شود (و میوت/دیفن را نشان می‌دهد)
- نمایش «در حال بازی …» برای بازی‌های معروف و بازی‌هایی که خودتان اضافه می‌کنید
- اتصال به سرور تیم‌اسپیک (فایل `hs-teamspeak.exe` کنار برنامه)
- میوت/دیفن و Push-to-Talk سراسری (حتی وقتی پنجره پشت برنامه‌های دیگر است)
- نشان پیام خوانده‌نشده روی آیکون تسک‌بار و چشمک زدن
- بروزرسانی: «تنظیمات کاربر ← بروزرسانی ← بررسی بروزرسانی» یا خودکار هر ۶ ساعت؛ دانلود، بررسی امضای SHA-256 و نصب از داخل خود برنامه
- امکان تغییر آدرس سرور (برای وقتی که به سرور دیگری کوچ کنید)

فایل‌ها بعد از `npm run release` در پوشه‌ی `release/` ساخته می‌شوند. برای ساختن به Visual Studio Build Tools (C++) نیاز است.

### انتشار نسخه‌ی جدید (آپدیت دادن)

1. عدد `version` را در `package.json` بالا ببرید (مثلاً `1.3.0` → `1.4.0`).
2. توضیح تغییرات را در `desktop/release-notes.json` بنویسید.
3. `npm run deploy` را اجرا کنید.

همه‌ی برنامه‌های ویندوز نسخه‌ی جدید را پیدا می‌کنند و با یک کلیک آپدیت می‌شوند؛ نسخه‌ی وب هم همان لحظه بروز می‌شود.

## نصب روی سرور شخصی (مثلاً VPS ایرانی)

`npm run release` فایل `release/hamsohbat-server.zip` را می‌سازد: کل سرور در یک فایل (`server.mjs`) که روی Node.js 22.5+ و با یک فایل SQLite اجرا می‌شود. راهنمای کامل نصب (با HTTPS و TURN) داخل همان فایل است: `README-fa.md`.

## اجرا روی کامپیوتر خودتان

```bash
npm install
npm run dev
```

سپس `http://localhost:8787` را باز کنید. داده‌ها در پوشه‌ی `.wrangler` ذخیره می‌شوند.

## انتشار روی Cloudflare

```bash
npx wrangler login
npm run deploy
```

آدرس برنامه بعد از انتشار نمایش داده می‌شود (`https://hamsohbat.<نام-شما>.workers.dev`).
برای استفاده از دامنه‌ی خودتان، در داشبورد Cloudflare به Worker یک Custom Domain بدهید.

### تنظیمات اختیاری

| متغیر | کار |
| --- | --- |
| `REGISTRATION_CODE` | اگر مقدار داشته باشد، ثبت‌نام فقط با این کد ممکن است. با `npx wrangler secret put REGISTRATION_CODE` تنظیم کنید. |
| `TURN_KEY_ID` و `TURN_KEY_API_TOKEN` | کلید سرویس TURN کلاودفلر (Realtime → TURN در داشبورد). وقتی تماس مستقیم بین دو نفر برقرار نمی‌شود (پشت NAT سخت‌گیر یا بعضی اینترنت‌های موبایل) صدا از این مسیر رد می‌شود. |

## تست

```bash
npm run dev            # در یک ترمینال
npm test               # تست‌های API و وب‌سوکت
npm run test:features  # تست API امکانات دیسکوردی (رشته، نظرسنجی، رویداد، وب‌هوک، مدیر خودکار، ...)
npm run test:voice     # تست واقعی تماس، پیام صوتی، Push-to-Talk و پیش‌نمایش لینک با چند مرورگر Chrome
npm run test:ui        # تست رابط کاربری با دو مرورگر: انجمن، رشته، نظرسنجی، ایموجی، استیکر، صحنه، ساندبورد، 2FA و ...
npm run check:i18n     # پیدا کردن متن‌های بدون ترجمه‌ی فارسی
npm run release
npm run test:desktop   # اجرای واقعی برنامه‌ی ویندوز و تست بروزرسانی آن
```

تست‌های API، امکانات و رابط کاربری را می‌شود روی سرور شخصی هم اجرا کرد: `node test/api.test.mjs http://127.0.0.1:3000`
تست تیم‌اسپیک به یک سرور TeamSpeak 3 محلی نیاز دارد: `node test/teamspeak.test.mjs <رمز serveradmin>`

## ساختار

| مسیر | محتوا |
| --- | --- |
| `server/index.ts` | Worker و Durable Object: پایگاه‌داده‌ی SQLite، API، وب‌سوکت و سیگنالینگ تماس |
| `server/features.ts` | امکانات دیسکوردی: رشته و انجمن، نظرسنجی، رویداد، ایموجی/استیکر/ساندبورد، وب‌هوک، مدیر خودکار، 2FA، وارد کردن از دیسکورد |
| `selfhost/` | اجرای همان سرور روی Node.js برای VPS شخصی |
| `desktop/` | برنامه‌ی ویندوز (C++ و WebView2) و نصب‌کننده‌ی MSI (WiX) |
| `desktop/teamspeak/` | پل اتصال به تیم‌اسپیک (Rust) |
| `scripts/` | ساخت آیکون‌ها، سرور شخصی و نسخه‌ی نهایی |
| `shared/perms.ts` | ثابت‌های مشترک (دسترسی‌ها، نوع کانال‌ها) |
| `src/store.ts` | وضعیت برنامه و پردازش رویدادهای لحظه‌ای |
| `src/voice.ts` | موتور WebRTC (شبکه‌ی مش نظیربه‌نظیر) |
| `src/*.tsx` | رابط کاربری React |
| `src/features/` | رابط امکانات دیسکوردی (کانال‌ها، پیام‌ها، سرور، صدا، حساب) |
| `src/fa.ts` | ترجمه‌ی فارسی |

## محدودیت‌ها

- تماس‌ها نظیربه‌نظیر (mesh) هستند؛ برای جمع‌های دوستانه (حدود ۸ تا ۱۰ نفر در یک کانال) مناسب است، نه صدها نفر.
- این موارد از دیسکورد ساخته نشده‌اند (یا عمداً حذف شده‌اند): فروشگاه، کوئست، نیترو و بوست، گیف‌یاب (به کلید API سرویس خارجی نیاز دارد)، ربات‌های تعاملی (دستورهای اسلش؛ وب‌هوک‌ها کار می‌کنند)، بازیابی رمز با ایمیل و اپ بومی موبایل (نسخه‌ی وب روی موبایل کار می‌کند و قابل نصب است).
- وارد کردن پیام‌ها از دیسکورد به یک ربات با «Message Content Intent» نیاز دارد؛ دیسکورد اجازه نمی‌دهد با حساب شخصی پیام‌ها خوانده شوند.
- برنامه‌ی ویندوز امضای دیجیتال ندارد؛ بار اول ویندوز پیام «Windows protected your PC» نشان می‌دهد: More info ← Run anyway.

## ساخت از سورس (متن‌باز)

```bash
npm install
echo https://hamsohbat.<نام-شما>.workers.dev > server-url.txt   # آدرس پیش‌فرض برنامه‌ی ویندوز
node scripts/setup-desktop.mjs   # دانلود WebView2 SDK و tsclientlib
npm run release                  # نیاز به Visual Studio Build Tools، Rust و WiX
```

پروژه با مجوز MIT منتشر شده است (فایل `LICENSE`). کتابخانه‌های شخص ثالث: tsclientlib (MIT/Apache-2.0)، nnnoiseless و RNNoise (BSD)، GTCRN و web-noise-suppressor (MIT)، WebView2 (مجوز مایکروسافت).

### رله‌ی TURN (وقتی تماس وصل نمی‌شود)
اگر دو نفر پشت اینترنت‌های سخت‌گیر هستند، تماس مستقیم برقرار نمی‌شود و فقط «در حال اتصال» می‌بینند. برنامه به‌طور پیش‌فرض یک رله‌ی عمومی (Open Relay) را امتحان می‌کند؛ برای پایداری بهتر یک کلید TURN رایگان در Cloudflare بسازید (Realtime ← TURN) و `TURN_KEY_ID` و `TURN_KEY_API_TOKEN` را مطابق بخش «تنظیمات اختیاری» تنظیم کنید.
